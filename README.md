# ConstructVision
Built and deployed a Django-based construction monitoring platform using MobileNetV2 + LSTM to
classify project completion stages from image and video inputs with 90%+ accuracy.
• Designed preprocessing and inference pipeline for real-time progress analysis across multiple construction
stages (0%–100%), processing 30+ frames per second.
• Deployed scalable inference service on AWS EC2 with integrated video processing, REST APIs, and
cloud-hosted monitoring workflow serving multiple concurrent users.
